# Salvage Array — Ship Upgrades

**Concept:** Salvage Array — Ship Upgrades is a medium Hadal detail within the Ship Upgrades category. It exists to support persistent upgrades that change expedition capability without removing uncertainty.

Its baseline pressure is **rare but severe**. Players most reliably identify or understand it through **crew comparison of conflicting evidence**. The intended response is usually to **slow down and verify**, rather than treating every problem as combat.

## Progression value
