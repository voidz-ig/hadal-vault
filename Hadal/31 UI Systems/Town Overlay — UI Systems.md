# Town Overlay — UI Systems

**Concept:** Town Overlay — UI Systems is a small Hadal detail within the UI Systems category. It exists to support interface systems designed to communicate pressure without making uncertainty disappear.

## Gameplay role
Its baseline pressure is **deceptively minor**. Players most reliably identify or understand it through **crew comparison of conflicting evidence**. The intended response is usually to **communicate a confirmation phrase**, rather than treating every problem as combat.

## Sensory identity
A recurring tell is radio static with a human cadence. It can leave evidence that persists back in town.

## Progression value
Interacting with, surviving, repairing, studying or exploiting this detail can contribute to **safer future routes**. Deeper versions should connect back to [[Depth Escalation]] and become less certain rather than simply gaining more health.
