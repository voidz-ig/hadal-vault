# Ship Overlay — UI Systems

**Concept:** Ship Overlay — UI Systems is a medium Hadal detail within the UI Systems category. It exists to support interface systems designed to communicate pressure without making uncertainty disappear.

## Gameplay role
Its baseline pressure is **low but persistent**. Players most reliably identify or understand it through **radio behavior**. The intended response is usually to **change route rather than fight**, rather than treating every problem as combat.

## Sensory identity
A recurring tell is a brief absence of ordinary ocean noise. Experienced crews notice it earlier but may overreact.

## Progression value
Interacting with, surviving, repairing, studying or exploiting this detail can contribute to **research value**. Deeper versions should connect back to [[Depth Escalation]] and become less certain rather than simply gaining more health.
