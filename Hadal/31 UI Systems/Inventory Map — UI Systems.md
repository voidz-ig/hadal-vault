# Inventory Map — UI Systems

**Concept:** Inventory Map — UI Systems is a small Hadal detail within the UI Systems category. It exists to support interface systems designed to communicate pressure without making uncertainty disappear.

## Gameplay role
Its baseline pressure is **deceptively minor**. Players most reliably identify or understand it through **radio behavior**. The intended response is usually to **slow down and verify**, rather than treating every problem as combat.

## Sensory identity
A recurring tell is a smell of wet iron. It is easier to survive than to correctly understand.

## Progression value
Interacting with, surviving, repairing, studying or exploiting this detail can contribute to **rare crafting material**. Deeper versions should connect back to [[Depth Escalation]] and become less certain rather than simply gaining more health.
