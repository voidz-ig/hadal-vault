# Threat Panel — UI Systems

**Concept:** Threat Panel — UI Systems is a small Hadal detail within the UI Systems category. It exists to support interface systems designed to communicate pressure without making uncertainty disappear.

## Gameplay role
Its baseline pressure is **low but persistent**. Players most reliably identify or understand it through **sound pattern recognition**. The intended response is usually to **retreat before escalation**, rather than treating every problem as combat.

## Sensory identity
A recurring tell is a brief absence of ordinary ocean noise. Its first explanation is usually mundane.

## Progression value
Interacting with, surviving, repairing, studying or exploiting this detail can contribute to **equipment access**. Deeper versions should connect back to [[Depth Escalation]] and become less certain rather than simply gaining more health.
