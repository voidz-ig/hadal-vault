# Inventory Prompt — UI Systems

**Concept:** Inventory Prompt — UI Systems is a small Hadal detail within the UI Systems category. It exists to support interface systems designed to communicate pressure without making uncertainty disappear.

## Gameplay role
Its baseline pressure is **rare but severe**. Players most reliably identify or understand it through **visual observation**. The intended response is usually to **communicate a confirmation phrase**, rather than treating every problem as combat.

## Sensory identity
A recurring tell is a brief absence of ordinary ocean noise. It becomes more dangerous when players stop communicating.

## Progression value
Interacting with, surviving, repairing, studying or exploiting this detail can contribute to **money and town recovery**. Deeper versions should connect back to [[Depth Escalation]] and become less certain rather than simply gaining more health.
