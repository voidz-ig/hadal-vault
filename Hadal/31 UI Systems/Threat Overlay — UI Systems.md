# Threat Overlay — UI Systems

**Concept:** Threat Overlay — UI Systems is a small Hadal detail within the UI Systems category. It exists to support interface systems designed to communicate pressure without making uncertainty disappear.

## Gameplay role
Its baseline pressure is **high under bad conditions**. Players most reliably identify or understand it through **visual observation**. The intended response is usually to **slow down and verify**, rather than treating every problem as combat.

## Sensory identity
A recurring tell is light scattering that looks slightly delayed. Its first explanation is usually mundane.

## Progression value
Interacting with, surviving, repairing, studying or exploiting this detail can contribute to **research value**. Deeper versions should connect back to [[Depth Escalation]] and become less certain rather than simply gaining more health.
