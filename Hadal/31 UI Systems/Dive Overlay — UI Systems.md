# Dive Overlay — UI Systems

**Concept:** Dive Overlay — UI Systems is a small Hadal detail within the UI Systems category. It exists to support interface systems designed to communicate pressure without making uncertainty disappear.

## Gameplay role
Its baseline pressure is **low but persistent**. Players most reliably identify or understand it through **sonar or instrument drift**. The intended response is usually to **change route rather than fight**, rather than treating every problem as combat.

## Sensory identity
A recurring tell is radio static with a human cadence. Experienced crews notice it earlier but may overreact.

## Progression value
Interacting with, surviving, repairing, studying or exploiting this detail can contribute to **safer future routes**. Deeper versions should connect back to [[Depth Escalation]] and become less certain rather than simply gaining more health.
