# Crew Map — UI Systems

**Concept:** Crew Map — UI Systems is a small Hadal detail within the UI Systems category. It exists to support interface systems designed to communicate pressure without making uncertainty disappear.

## Gameplay role
Its baseline pressure is **deceptively minor**. Players most reliably identify or understand it through **crew comparison of conflicting evidence**. The intended response is usually to **split responsibilities**, rather than treating every problem as combat.

## Sensory identity
A recurring tell is sediment moving against the current. Experienced crews notice it earlier but may overreact.

## Progression value
Interacting with, surviving, repairing, studying or exploiting this detail can contribute to **rare crafting material**. Deeper versions should connect back to [[Depth Escalation]] and become less certain rather than simply gaining more health.
