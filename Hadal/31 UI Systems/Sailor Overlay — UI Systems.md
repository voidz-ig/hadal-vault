# Sailor Overlay — UI Systems

**Concept:** Sailor Overlay — UI Systems is a small Hadal detail within the UI Systems category. It exists to support interface systems designed to communicate pressure without making uncertainty disappear.

## Gameplay role
Its baseline pressure is **high under bad conditions**. Players most reliably identify or understand it through **sonar or instrument drift**. The intended response is usually to **split responsibilities**, rather than treating every problem as combat.

## Sensory identity
A recurring tell is light scattering that looks slightly delayed. Its first explanation is usually mundane.

## Progression value
Interacting with, surviving, repairing, studying or exploiting this detail can contribute to **money and town recovery**. Deeper versions should connect back to [[Depth Escalation]] and become less certain rather than simply gaining more health.
