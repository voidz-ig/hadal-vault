# Inventory Meter — UI Systems

**Concept:** Inventory Meter — UI Systems is a small Hadal detail within the UI Systems category. It exists to support interface systems designed to communicate pressure without making uncertainty disappear.

## Gameplay role
Its baseline pressure is **rare but severe**. Players most reliably identify or understand it through **sound pattern recognition**. The intended response is usually to **communicate a confirmation phrase**, rather than treating every problem as combat.

## Sensory identity
A recurring tell is a smell of wet iron. Experienced crews notice it earlier but may overreact.

## Progression value
Interacting with, surviving, repairing, studying or exploiting this detail can contribute to **rare crafting material**. Deeper versions should connect back to [[Depth Escalation]] and become less certain rather than simply gaining more health.
