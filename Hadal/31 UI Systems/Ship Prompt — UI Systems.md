# Ship Prompt — UI Systems

**Concept:** Ship Prompt — UI Systems is a small Hadal detail within the UI Systems category. It exists to support interface systems designed to communicate pressure without making uncertainty disappear.

## Gameplay role
Its baseline pressure is **moderate**. Players most reliably identify or understand it through **visual observation**. The intended response is usually to **communicate a confirmation phrase**, rather than treating every problem as combat.

## Sensory identity
A recurring tell is light scattering that looks slightly delayed. Experienced crews notice it earlier but may overreact.

## Progression value
Interacting with, surviving, repairing, studying or exploiting this detail can contribute to **research value**. Deeper versions should connect back to [[Depth Escalation]] and become less certain rather than simply gaining more health.
