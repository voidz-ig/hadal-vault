# Ship Meter — UI Systems

**Concept:** Ship Meter — UI Systems is a small Hadal detail within the UI Systems category. It exists to support interface systems designed to communicate pressure without making uncertainty disappear.

## Gameplay role
Its baseline pressure is **low but persistent**. Players most reliably identify or understand it through **radio behavior**. The intended response is usually to **communicate a confirmation phrase**, rather than treating every problem as combat.

## Sensory identity
A recurring tell is radio static with a human cadence. Its behavior subtly changes after deeper expeditions.

## Progression value
Interacting with, surviving, repairing, studying or exploiting this detail can contribute to **money and town recovery**. Deeper versions should connect back to [[Depth Escalation]] and become less certain rather than simply gaining more health.
