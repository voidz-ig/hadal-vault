# Crew Meter — UI Systems

**Concept:** Crew Meter — UI Systems is a medium Hadal detail within the UI Systems category. It exists to support interface systems designed to communicate pressure without making uncertainty disappear.

## Gameplay role
Its baseline pressure is **deceptively minor**. Players most reliably identify or understand it through **visual observation**. The intended response is usually to **retreat before escalation**, rather than treating every problem as combat.

## Sensory identity
A recurring tell is sediment moving against the current. It can leave evidence that persists back in town.

## Progression value
Interacting with, surviving, repairing, studying or exploiting this detail can contribute to **money and town recovery**. Deeper versions should connect back to [[Depth Escalation]] and become less certain rather than simply gaining more health.
