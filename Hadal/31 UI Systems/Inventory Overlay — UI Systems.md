# Inventory Overlay — UI Systems

**Concept:** Inventory Overlay — UI Systems is a medium Hadal detail within the UI Systems category. It exists to support interface systems designed to communicate pressure without making uncertainty disappear.

## Gameplay role
Its baseline pressure is **low but persistent**. Players most reliably identify or understand it through **visual observation**. The intended response is usually to **communicate a confirmation phrase**, rather than treating every problem as combat.

## Sensory identity
A recurring tell is a smell of wet iron. It can leave evidence that persists back in town.

## Progression value
Interacting with, surviving, repairing, studying or exploiting this detail can contribute to **new dialogue and rumors**. Deeper versions should connect back to [[Depth Escalation]] and become less certain rather than simply gaining more health.
